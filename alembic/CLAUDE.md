# alembic: schema migrations for the `app` Postgres database

Standalone `uv` project (`package = false`) with Alembic, SQLAlchemy 2 and psycopg 3.

## Setup / commands
```bash
uv sync
uv run alembic revision -m "describe change"      # new migration in migrations/versions/
uv run alembic upgrade head
uv run alembic downgrade -1
uv run alembic current
uv run alembic history
```

## Configuration
- `alembic.ini`: `sqlalchemy.url` should be `postgresql+psycopg://postgres:postgres@localhost:5432/app` (psycopg 3 driver, not psycopg2). The Databases stack must be running.
- `migrations/`: generated by `alembic init`; `env.py` is where autogenerate / metadata is configured.

## Status and plan

Planned: move that definition into a migration (`order_id integer PK, customer text, amount numeric(10,2), order_date date`) and remove the `CREATE TABLE` from the ETL activity.
